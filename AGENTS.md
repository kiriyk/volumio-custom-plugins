# Работа с Git

- Коммить и пушь согласованные изменения после успешной проверки. «Ок,
  продолжай» и аналогичное подтверждение дают разрешение на коммит и пуш в
  уже согласованных границах. Если проверенная правка закончена и работа
  перешла к другой задаче, зафиксируй и отправь завершённые изменения без
  повторного запроса разрешения. Прямое указание пользователя отложить
  коммит или пуш имеет приоритет.
- Делай коммиты по смысловым блокам. Включай только согласованные изменения,
  сохраняя посторонние правки и незавершённую работу.
- Пушь рабочую ветку по мере готовности проверенных блоков. Когда ветка
  содержит законченный согласованный блок, влей её в `main`, проверь
  результат слияния и запушь `main`. Остальные ветки доводи и вливай
  независимо по мере готовности.
