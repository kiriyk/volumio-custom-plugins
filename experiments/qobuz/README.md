# Эксперимент Qobuz

Исследовательские скрипты для проверки входа, каталога и аудиопотока на Raspberry Pi с Volumio. **Не плагин и не готовый установщик.** Результаты: [исследование](../../docs/research/2026-11-10-qobuz.md).

- `callback.py` — временный браузерный OAuth callback, порт 17900, максимум час работы. Принимает `code_autorisation` и `code`; сохраняет сессию локально с правами 0600. После успешного эксперимента процесс был остановлен.
- `probe.py` — поиск одного трека, получение прямого FLAC и проверка первых 64 КиБ через ffprobe. Аргумент `6`, `7` или `27` задаёт запрашиваемый формат; без аргумента — `6`. Фактически возвращённое качество может отличаться.
- `mpd_probe.py` — отдельный MPD на 127.0.0.1:16601 с null-выходами; проверяет паузу, продолжение, перемотку и полное декодирование. Требует предварительного получения `stream-hires.json` командой `probe.py 27`. Не подключается к ALSA и основному MPD.
- `test_callback.py` — три проверки callback без аккаунта: `python3 experiments/qobuz/test_callback.py`.

Рабочие файлы `parameters.json` и `session.json` намеренно отсутствуют. Они создавались в закрытом временном каталоге при запуске эксперимента. Проверенный вход на устройстве сохранён в `/data/qobuz-research`; не копировать этот каталог в Git или публичные архивы. Скрипты используют каталог своего расположения для временных файлов; запускать только в закрытом рабочем каталоге. После обновления/истечения сессии может потребоваться повторный вход.

Схема `parameters.json` без значений: `app_id`, `oauth_parameter`, `stream_candidates` (массив), `callback_path` (случайный путь возврата). Схема `session.json`: `token`, `user_id`, `has_subscription_parameters`, `created_at`. Параметры веб-клиента при эксперименте определялись библиотекой из upmpdcli 1.10.1; сама библиотека и реквизиты в этот каталог не включены. Готовой процедуры получения реквизитов для собственного публичного приложения здесь нет.

Референсы: [upmpdcli](https://www.lesbonscomptes.com/upmpdcli/pages/upmpdcli-manual.html), [варианты callback в cliamp](https://github.com/bjarneo/cliamp/blob/main/external/qobuz/session.go). Полные упакованные модули Volumio не копировались. Собственные скрипты этого каталога распространяются по MIT (см. `LICENSE`).
