# Минимальный независимый Qobuz-плагин

Пользователь поручил продолжить после успешного эксперимента. Предложенный самостоятельный клиент принят последовательными командами продолжения; повторное согласование того же направления не требуется.

Цель: устанавливаемый `music_service/qobuz_custom` для Volumio 4 / Bookworm, Node >=20, Python >=3.11, Raspberry Pi armhf. Вход через браузер, сохранение сессии, поиск треков и альбомов, любимые альбомы на чтение, пагинация альбома, штатная очередь MPD, пауза/продолжение/перемотка. Качество: максимальный FLAC или CD FLAC; показывать реально полученные параметры, без скрытого перехода на MP3.

Рассмотрены копирование упакованного штатного клиента, зависимость от upmpdcli и самостоятельный адаптер. Выбран самостоятельный адаптер: исследование подтвердило прямой FLAC без менеджера подписки Volumio. Используется неофициальный веб-интерфейс Qobuz; изменяемые детали протокола изолированы.

Node-контроллер регистрирует источник и обслуживает Volumio API. Python/aiohttp-сервис слушает управление и поток на 127.0.0.1:17901; отдельный порт 17900 принимает только OAuth callback со случайным путём, ограниченным сроком жизни и одноразовым завершением. Код `code_autorisation` и `code` обменивается сервером, токен не возвращается в UI. Вход и параметры хранятся только в `/data/configuration/music_service/qobuz_custom`, 0700/0600. При первой установке допустим перенос ранее проверенной сессии из `/data/qobuz-research`, если входа ещё нет. Установка/обновление сессию не уничтожает, logout аннулирует потоковые билеты.

Для MPD используются непрозрачные локальные URL; токены и подписанные CDN-ссылки не попадают в очередь или логи Volumio. Поток передаётся без перекодирования, с Range/HEAD, ограниченной параллельностью и памятью. Допускаются только HTTPS CDN Qobuz/Akamai с проверкой каждого перенаправления; без универсального прокси. Отмена старого запроса при смене трека/источника не должна запускать его позже.

Artwork One: поиск для нового источника, хлебные крошки, логотип из уже поставляемого ресурса Qobuz, фактическое качество с привязкой к URI. Доработки Яндекса сохраняются. Скачивание, полная коллекция, страницы исполнителей, Qobuz Connect и переключатель bit-perfect — последующие этапы.

Проверки: тесты на ошибки авторизации, пагинацию, фактический формат, приватное хранение, HTTP Range, остановку/смену источника; один целевой прогон на Pi. Установку/enable выполнить без перезапуска Volumio и без изменения пользовательской очереди. Для живого MPD использовать изолированный null-выход. Архив и исходники сохранить на GitHub; реквизиты в пакет не включать.
