## Реализация

Python хранит в памяти одну локальную сессию, полученные треки, партии и
события; на диск записывает только проверенный выбор. Все операции `/v1/wave`
защищены существующим внутренним API-ключом. OAuth и аудиоссылки в интерфейс
волны не передаются. Смена аккаунта очищает контекст.

Контроллер сериализует команды, отбрасывает устаревшие ответы, проверяет
владение очередью, подгружает партии и ограничивает историю 20 треками.
Метаданные уже проверенной партии используются при штатном explodeUri,
без повторного запроса каждого трека. Будущая очередь содержит максимум
две партии. Собственные изменения очереди не отключают обработку playback.

Общий транспортный сигнал различает EOF, Stop и ошибки. MPD сохраняет
логический источник, использует длительность декодера и подтверждает первый
play даже без второго status-уведомления. Общий observer MPD корректно
освобождается при смене источников. Прослушанное время не включает паузы,
seek и ожидание следующего трека. Feedback дедуплицируется по экземпляру
воспроизведения.

Artwork One и штатные настройки управляют одним выбором на Pi. Изменение
полей остаётся черновиком до кнопки применения; клиенты синхронизируются
через pushYandexWave и запрашивают состояние после переподключения.

| Перезапуск | Волна не запускается автоматически |
| Состояние Pi после проверки | Исходные очередь и настройки движка восстановлены; авторизация сохранена, checksum credentials.json совпал |

Аппаратный прогон ускорен seek за четыре секунды до конца треков. Длительный
прогон целых треков без перемотки не выполнялся. API-пробники не засчитывались
как проверка воспроизведения. Сценарии воспроизведения и API находятся в
`yandex-music/tests/live/wave_{smoke,controls}.js` и `wave_api.py`;
описание запуска — [testing.md](../yandex-music/docs/testing.md).

Во время проверки обнаруживались ошибки внешнего API; они завершали режим
с явным сообщением. Автоматических повторов и перехода на старое радио нет.
Код Core на диске не изменялся. Резервная копия исходных плагинов на Pi:
`/data/wave-release-backup/plugins-before.tar.gz`.
