# Проверка публикации, 2026-11-11

Проверен публичный монорепозиторий GitHub: 11 коммитов, 463 уникальных Git blob и содержимое 7 архивов пакетов, включая старые версии. Общий скан Gitleaks 8.30.1 выполнен с полной редакцией значений в выводе. Проверка точных совпадений выполнена на самом плеере: 829 файлов, 14 действующих секретных значений и 3 идентификатора аккаунта. Учётные данные не копировались в репозиторий или локальный отчёт.

Совпадений с действующими токенами, секретными параметрами и логином/email сервисного аккаунта не найдено. Короткое отображаемое имя профиля совпадает с общим словом в коде и лицензиях; это не запись данных профиля. Пароль SSH по умолчанию и системное имя volumio используются в инструкциях как общеизвестные значения.

Gitleaks отметил только публичную клиентскую конфигурацию Firebase из исходной темы Volumio, включая её копии в собранных пакетах. Это не токен аккаунта пользователя. Правила доступа Firebase на стороне владельца проекта этой проверкой не оценивались. См. https://firebase.google.com/docs/projects/api-keys.

Обычный email в метаданных старых коммитов оставлен по прямому указанию пользователя. История не переписывалась. Для следующих коммитов локально выбран GitHub noreply.

Файлы credentials.json, api-key, локальные .env и каталог qobuz-research добавлены в .gitignore. Сборка Qobuz использует явный список публичных исходников и исключает credentials.json/api-key. Данные входа хранятся отдельно в конфигурации плеера. .gitignore не защищает уже отслеживаемые файлы и не заменяет проверку будущих публикаций. Проверка относится к указанному монорепозиторию и его пакетам, а не ко всем сторонним репозиториям или серверным логам.

Дополнительно просканированы распакованные новые пакеты Qobuz 0.2.1 и Artwork One: единственное срабатывание — та же публичная Firebase-конфигурация в собранном JavaScript.
