# Qobuz Custom 0.2.0 — проверка 11 ноября 2026

Исправления навигации после поиска, качества при `service=mpd`, меню/иконок; отдельный поиск с источниками под строкой. Добавлены поиск/избранное исполнителей, пагинация дискографии и скачивание оригинального FLAC на подключённый внешний диск.

## Автоматические проверки

- 38 Python-тестов, включая 11 проверок загрузчика: отсутствие mountpoint, безопасные Unicode/exFAT пути, место/размер, отмена/выход, очередь, повторный файл, атомарная публикация и отказ чужим перенаправлениям. Загрузчик проверяется тестовым HTTP-сервером и FLAC-образцом.
- 8 Node-тестов: страницы/ссылки исполнителей, постраничная очередь, отмена старого resolve, качество, чтение MPD-статуса только у Qobuz и повторная индексация после ошибки.
- 8 проверок UI helpers для поиска/крошек/качества, production-сборка Artwork One.
- Один итоговый просмотр: исправлены преждевременная отметка индексации после сбоя MPD и действия Play/Shuffle для страницы исполнителя, не поддерживающей разворачивание всех треков.

## Устройство

- Установлено обновление без удаления конфигурации, вход сохранился. Для нового Node-кода выполнен один перезапуск Volumio во время паузы. Очередь до и после — **204 трека**; резервная копия сохранена локально на Pi.
- Новая служба работает под volumio, с минимальной CAP_DAC_OVERRIDE и ограничением записи ProtectSystem=strict/state/media. Это позволяет сохранить на exFAT с root-владельцем без отмонтирования или смены владельца тома.
- Настоящая загрузка через Node-действие: Get Lucky, ID 8767428. Итог `completed`, файл **51 528 731 байт**, FLAC **24 бит / 44 100 Гц**. mutagen подтвердил теги title/artist/album и аудиопараметры.
- Файл: `qobuz/Daft Punk ft. Pharrell Williams/Get Lucky/Get Lucky [8767428].flac` на External_HD. Полный абсолютный каталог — `/media/External_HD/qobuz/...`.
- После завершения MPD подтвердил **один проиндексированный файл** в `USB/External_HD/qobuz`.
- Браузер: видны отдельный «Поиск», Qobuz в боковом меню и кнопки источников. Поиск Daft Punk в Qobuz дал группы исполнителей/альбомов/треков; строка запроса сохраняется при выборе источника. Проверены переходы из результатов к исполнителю и альбому с хлебными крошками.

## Границы

Физическое отключение диска во время записи не выполнялось; отказ без mountpoint и прерывание проверены тестами. Обложка в сохраняемый FLAC отдельно не добавляется, аудио не перекодируется. Очередь/история загрузок ограничена и хранится до перезапуска службы; завершённые файлы остаются на диске. Скачивание целого альбома одной кнопкой и Qobuz Connect не входят в этот этап.
