# Приёмка Qobuz Custom 0.1.0 — 10 ноября 2026

Volumio 4.239 / Bookworm, Raspberry Pi 4 armhf, Node 20.5.1, Python 3.11.2, MPD 0.24.6.

- 17 Python-тестов: состояние/права, callback, запросы API, пагинация, качество, локальная авторизация, настоящий тестовый HTTP Range 206, выход и отмена незавершённого resolve, старый 401 после нового входа.
- 4 Node-теста: отмена запоздавшего воспроизведения, фактическое качество, многократные треки и пагинация очереди, защита от зацикленного курсора.
- 5 проверок вспомогательных функций темы для поиска, навигации и качества Яндекса, Qobuz и локальных файлов; production-сборка Artwork One прошла.
- Установка штатным CLI Volumio и включение через pluginManager. Core не перезапускался. Источник Qobuz Custom появился, getUIConfig показал «Вход выполнен», корневой browse вернул «Любимые альбомы».
- Сессия из согласованного эксперимента перенесена в собственную конфигурацию без вывода или публикации реквизитов.
- Реальный поиск: 22 результата альбомов для Random Access Memories, 50 треков для Get Lucky; открытый альбом вернул 13 треков. Любимые альбомы вернули первую страницу из 50 записей.
- Выдача потока через установленный сервис вернула FLAC, 24 бит / 44 100 Гц. Локальный ticket URL ответил HTTP 206 и 1024 байта с сигнатурой fLaC.
- Изолированный MPD через локальный HTTP-посредник плагина подтвердил `44100:24:2`, pause/resume, seek на 30 секунд (факт 30,171 секунды) и завершение полного декодирования трека Get Lucky длительностью 247 секунд. Null-выход без синхронизации завершил его примерно за 20 секунд; ALSA и основной MPD не использовались.
- При итоговом просмотре исправлены и покрыты воспроизводящими тестами две гонки: поздняя выдача билета после logout и очистка нового входа старым 401. На устройстве обновлены файлы и перезапущена только служба Qobuz; основная очередь не менялась. Состояние входа после исправления подтверждено.

Проверка не подтверждает слышимое звучание, bit-perfect, длительную устойчивость к обрывам сети или бессрочное сохранение сессии. Повторный вход через настройки именно установленной версии после импорта сессии заново не проходился; тот же обмен кода отдельно подтверждён живым экспериментом, callback плагина покрыт моделированными тестами. Финальный UI в браузере и воспроизведение из пользовательской очереди должен проверить владелец.

Потоковые URL не являются постоянными: после перезапуска Python трек нужно запустить заново. Качество определяется конкретным изданием; запрос максимального формата не означает обязательные 192 кГц.
