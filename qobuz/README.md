# Qobuz Custom для Volumio 4

Независимый источник `music_service/qobuz_custom`: поиск треков, альбомов и исполнителей, любимые альбомы/исполнители на чтение, дискография, список треков альбома и очередь Volumio. Версия 0.2.1 добавляет встроенные обложки к скачиваемым FLAC. Требует собственной действующей подписки Qobuz. Использует неофициальный веб-интерфейс сервиса, который может измениться.

Целевое окружение: Volumio 4 / Bookworm, Node >=20, Python >=3.11, armhf или amd64. Qobuz Connect и редактирование коллекции не включены.

## Установка и обновление

Скачать `packages/qobuz_custom-0.2.1.tar.gz` из монорепозитория, перенести на Pi и распаковать. В каталоге `qobuz_custom` выполнить `volumio plugin install`. Для обновления уже установленного плагина использовать `node scripts/update.js .`: это сохраняет настройки и вход. Не выполнять uninstall/install для обновления. После изменения Node-кода нужен перезапуск Volumio, чтобы загрузился новый модуль.

Включить **Qobuz Custom** в Plugins. Служба `volumio-qobuz-custom.service` запускается и останавливается плагином. Другие службы и настройки MPD/ALSA не меняются. На данной Pi первая установка переносит ранее подтверждённую исследовательскую сессию; на новой прошивке нужно войти заново.

## Вход

В настройках плагина нажать «Начать вход», затем «Открыть вход в Qobuz». Браузер должен находиться в той же сети, что и Pi. Вход выполняется на сайте Qobuz; пароль плагин не получает. После страницы успеха вернуться в настройки и нажать «Обновить статус». Ссылка действует 10 минут и используется один раз. После неудачного обмена начать новый вход.

Плагин использует IPv4-адрес устройства, предпочитая eth0/wlan0. При смене сети или нескольких сетевых адаптерах проверить доступность Pi из браузера. Не пробрасывать callback через интернет. Ошибка истечения сессии требует нового входа; автоматическое продление не обещается.

## Качество и воспроизведение

«Максимальный доступный FLAC» запрашивает формат 27, при необходимости 7 или 6. «CD FLAC» запрашивает формат 6. MP3 не используется как скрытый запасной вариант. Фактическая частота/разрядность берётся из ответа на выдачу текущего потока: например, запрос 27 может вернуть 24 бит / 44,1 кГц. Доступность зависит от конкретного издания и аккаунта. Плагин не перекодирует поток и не переключает микшер или ресемплер; bit-perfect всего тракта отдельно не подтверждён.

Альбом можно добавить в штатную очередь. При пагинации сохраняются повторные треки и порядок; недоступные треки пропускаются. Ограничение одной операции — 2000 доступных треков. Исполнитель открывается из поиска, избранного и меню трека; дискография загружается страницами. Полный список треков исполнителя и редактирование избранного пока не реализованы.

## Скачивание на внешний диск

В Artwork One в меню трека или «Сейчас играет» выбрать **«Скачать на внешний диск»**. Каталог строго `/media/External_HD/qobuz/исполнитель/альбом`; имя файла содержит название и ID трека. Нужен подключённый том External_HD. При отсутствии диска загрузка не начинается, SD-карта не используется. Папки создаются по мере необходимости, существующие корректные FLAC не перезаписываются.

В разделе Qobuz → Загрузки видны прогресс и отмена. Загрузка идёт по одному файлу, очередь ограничена 32 задачами; сервис хранит до 128 записей истории до перезапуска. Оригинальный FLAC не перекодируется; добавляются теги названия, исполнителя, альбома, номера трека/диска. При новых загрузках обложка Qobuz встраивается в FLAC, если доступна; отсутствие обложки не мешает сохранению аудио. Уже сохранённые файлы остаются без изменений. После завершения обновляется папка `USB/External_HD/qobuz` в индексе MPD.

Для exFAT с владельцем root служба остаётся под пользователем volumio и получает только CAP_DAC_OVERRIDE; ProtectSystem=strict сохраняется, запись разрешена в конфигурацию и `/media`. Диск не отмонтируется и права других процессов не меняются. Загрузчик дополнительно проверяет mountpoint и пути, не допускает symlink/traversal, ограничивает файл 2 ГиБ и оставляет 64 МиБ свободного места. Незавершённые файлы публикуются атомарно только после проверки FLAC. При физическом отсоединении диска возможен оставшийся `.part`, который намеренно не удаляется через отсутствующий mountpoint.

## Состояние и восстановление

Конфигурация хранится в `/data/configuration/music_service/qobuz_custom` с правами 0700/0600. Токены, реквизиты веб-клиента и подписанные CDN-ссылки не включаются в публичный архив. MPD получает случайный локальный URL, а не OAuth-токен. После перезапуска Python старый URL недействителен — трек нужно запустить заново.

API и поток: `127.0.0.1:17901`; отдельный порт 17900 обслуживает только OAuth callback со случайным путём. Параллельные аудиозапросы ограничены четырьмя. Каталог кэшируется только на стороне интерфейса; постоянной копии каталога нет. Для восстановления установить этот пакет и войти в Qobuz. Удаление плагина удаляет его конфигурацию и вход.

```bash
systemctl status volumio-qobuz-custom.service
curl http://127.0.0.1:17901/health
```

Не публиковать конфигурацию или полные отладочные дампы аккаунта. Ошибки сервиса выводятся в UI как фиксированные коды без текста ответа Qobuz.

npm test
