# Яндекс Музыка для Volumio 4

Нативный источник `music_service/yandex_music`: вход по коду устройства,
поиск треков/альбомов/исполнителей/плейлистов, собственная коллекция,
обложки и воспроизведение через очередь Volumio. Управление — штатный интерфейс
Volumio на телефоне или компьютере. API Яндекс Музыки неофициальный.

Целевая система: Volumio 4 / Bookworm, Node >=20, Python >=3.11,
userspace armhf или amd64. Проверенное окружение: Raspberry Pi 4, 4 ГБ,
Volumio 4.239, Node 20.5.1, Python 3.11.2, MPD 0.24.6.

Плагин может предпочитать FLAC (в том числе в контейнере MP4), использовать
только FLAC или MP3 до 320 кбит/с. Доступность зависит от аккаунта и трека;
режим предпочтения FLAC переходит на MP3, если Яндекс не вернул FLAC.
Для полного воспроизведения может требоваться подписка Яндекс Плюс.
Плагин не перекодирует аудио и не меняет ALSA/MPD-настройки.
«Моя волна», изменение коллекции и управление из приложения Яндекса
в эту версию не входят.

## Установка на Raspberry Pi

Включите SSH на `http://volumio.local/dev`. На компьютере в каталоге проекта:

```bash
bash scripts/deploy.sh volumio@volumio.local
```

Скрипт создаёт пакет, копирует по SSH и запускает штатный
`volumio plugin install`. Подтвердите ручную установку в CLI.
Для уже установленного плагина используется тот же API обновления Volumio через
`scripts/update.js`: штатный CLI 4.239 не завершает update при русском языке UI.
Нужен интернет для установки зависимостей. Установщик добавляет
`python3-venv`, `python3-dev`, `build-essential`, `ffmpeg`, если они отсутствуют,
и создаёт отдельный `.venv`; системные Node/Python не обновляются.

Вручную можно перенести `dist/yandex_music-0.2.1.tar.gz` на Pi,
распаковать, перейти в каталог `yandex_music` и выполнить:

```bash
volumio plugin install
```

Затем включите плагин в разделе Plugins / Installed plugins и откройте его
настройки. Установка сама не запускает Python-сервис: он запускается
при включении плагина и останавливается при отключении.
Установщик добавляет отдельное правило sudo, разрешающее пользователю volumio
только запуск и остановку `volumio-yandex.service`. При удалении правило удаляется.

## Вход и использование

1. В настройках нажмите «Войти по коду».
2. Откройте предложенную страницу Яндекса на телефоне, введите код и подтвердите
   вход. Состояние в настройках обновляется автоматически; есть кнопка проверки.
3. При недоступности Device Flow используйте поле готового OAuth-токена.
   Сохранённый токен обратно в интерфейс не возвращается.
4. Откройте Browse → Яндекс Музыка. Коллекция доступна на чтение.
5. Для поиска используйте лупу Volumio внутри источника или глобальный поиск.
   Страницы результатов и коллекции содержат «Ещё».
6. Альбом/плейлист можно добавить в очередь штатными действиями Volumio.
   За одну операцию допускается до 2000 треков; недоступные треки пропускаются
   с уведомлением. Повторные вхождения трека сохраняются.

Вход хранится между перезагрузками. При истечении сессии с refresh token
сервис пытается обновить её. Для токена без refresh token может потребоваться
повторный вход. Выход удаляет локальные credentials и аннулирует аудиопотоки.

## Обновление, откат и удаление

Восстановление плагина и нашей темы на новой прошивке описано в
[docs/RECOVERY.md](docs/RECOVERY.md). Отдельная утилита для исправления
известной ошибки Volumio Discovery поставляется в `scripts/`.

Перед обновлением сохраните предыдущий release-архив. Разверните новую версию
через `scripts/deploy.sh`: штатный update API не вызывает полный uninstall,
конфигурация и credentials сохраняются. Для отката распакуйте предыдущий архив
и выполните `node scripts/update.js .` из его каталога; совместимость версии
credentials должна быть проверена для релизов с изменением формата хранения.
После обновления перезапустите Volumio через системное меню: это очищает кэш
загруженного Node-кода. Скрипт сам не перезапускает проигрыватель во время музыки.

Для удаления используйте кнопку удаления плагина в Volumio. Будут удалены
собственный unit, venv и локальные credentials. Общие системные зависимости
сохраняются. Для обновления не используйте uninstall/install: это удалит вход.

## Диагностика и разработка

```bash
# На Pi
systemctl status volumio-yandex.service
journalctl -u volumio-yandex.service --since '10 minutes ago'
curl http://127.0.0.1:17899/health

# На компьютере
uv sync
npm ci
uv run pytest -q
npm test
bash scripts/package.sh
```

Сервис слушает только `127.0.0.1:17899`. Credentials и ключ внутреннего API
хранятся в `/data/configuration/music_service/yandex_music/` с правами 0600.
Не публикуйте этот каталог. Python access logging отключён; ошибки SDK
не сериализуются. Volumio Core может писать локальный stream URL в verbose-лог,
но этот URL не содержит OAuth-токен или подписанную ссылку Яндекса.

После перезапуска Python старые stream tickets недействительны: запустите трек
заново, если продолжение после паузы не работает. Известные ограничения и
результаты аппаратной проверки — в [docs/testing.md](docs/testing.md).

Пакет использует `yandex-music` (LGPL-3.0-only) как отдельную зависимость;
исходники и лицензия библиотеки: <https://github.com/MarshalX/yandex-music-api>.
