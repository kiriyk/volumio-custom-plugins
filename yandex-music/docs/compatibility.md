## Прочитанные сигнатуры MPD-адаптера

Файл на устройстве: `/volumio/app/plugins/music_service/mpd/index.js`.

| Метод | Строка | Наблюдаемое поведение |
| --- | --- | --- |
| `clearAddPlayTrack(track)` | 2702 | Берёт `track.uri`; для обычного HTTP URL выполняет stop → clear → add → play; возвращает Promise |
| `seek(position)` | 2754 | Принимает миллисекунды, передаёт MPD секунды как `position / 1000` |
| `pause()` | 2778 | MPD-команда pause без явного параметра; поведение повторного вызова нужно учитывать |
| `resume()` | 2784 | MPD-команда play |
| `stop()` | 2790 | MPD-команда stop |

В файле есть и более раннее присваивание `seek` на строке 77; для прототипа
действует более позднее определение на строке 2754.

`clearAddPlayTrack` использует `sanitizeUri`, которое удаляет подстроки
`music-library/` и `mnt/`. Локальный stream URL не должен случайно содержать их.
На строке 2729 URL пишется в verbose-лог Core; в передаваемый URI нельзя включать
OAuth-токен или подписанную внешнюю ссылку Яндекса.

## Прочитанные участки state machine

Файл: `/volumio/app/statemachine.js`.

- `play(index)`, строка 984: выбирает plugin по `trackBlock.service`.
- Строки 1027–1028: вызывает `thisPlugin.clearAddPlayTrack(trackBlock)` без
  ожидания Promise. Обработка асинхронной ошибки обязательна внутри адаптера.
- Строки 1035–1036: продолжение после паузы вызывает `thisPlugin.resume()`.
- Маршрутизация seek передаёт плагину позицию в миллисекундах.
- `setConsumeUpdateService(value, ignoremeta, upnp)`, строка 1494: задаёт
  источник consume updates, флаг игнорирования metadata и флаг upnp;
  возвращает Promise. Значение `undefined` отключает consume mode.

Присутствие метода consume mode ещё не доказывает корректность полного маршрута
state updates. До реализации нужно дочитать обработку событий MPD, конца трека,
переключения сервиса и публикации состояния в UI, затем проверить на устройстве.

## Plugin manager

Файл: `/volumio/app/pluginmanager.js`.

- `updatePlugin(data)`, строка 917: отдельный путь обновления; в прочитанной части
  останавливает plugin, распаковывает пакет и проверяет зависимости до замены.
- При полном удалении строка 1533 удаляет
  `/data/configuration/<category>/<name>`. Credentials в каталоге плагина
  не переживут uninstall; локальный сценарий обновления нельзя строить как
  uninstall/install без отдельного механизма сохранения и восстановления.
- Полный путь обновления и CLI `volumio plugin install` ещё требуется прочитать
  перед написанием deploy/update-скрипта. Сохранение credentials при обновлении
  остаётся требованием, а не уже проверенным поведением нашего установщика.
